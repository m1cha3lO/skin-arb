# skin-arb
Arbitrage CS2 Skin Tracker

A tool that monitors CS2 skin prices across multiple online marketplaces, identifying discrepancies between them for potential profit, including selling fees.
Will Retrieve listings from one marketplace and normalize their important attributes into a form that can eventually be compared with listings from another marketplace.

Out of Scope:
  automated purchases
  automated selling
  AWS
  machine learning
  arbitrage execution
  bypassing API restrictions
  scraping where prohibited
